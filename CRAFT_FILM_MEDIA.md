# OzaBay Craft Film — Media Notes

The Craft Film now uses real artisan pottery footage as the primary background layer, with a local OzaBay film as an automatic fallback if the remote source cannot load.

Primary footage sources:
- Pexels video 37306917 — https://www.pexels.com/video/artisan-pottery-crafting-on-a-traditional-wheel-37306917/
- Pexels video 9363486 — https://www.pexels.com/video/a-person-molding-clay-on-a-pottery-wheel-9363486/

The UI keeps the OzaBay navy/cream/gold treatment, adds a restrained cinematic wash, soft film grain, stage crossfades, and a subtle LIVE CRAFT FILM indicator. No vibration/jitter animation is used.

For production, download and self-host the licensed source clips under `public/videos/` if you want the site to work without an external media connection or if the hosting provider changes the media URL.
