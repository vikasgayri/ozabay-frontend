# OzaBay Custom Request — V5

The made-to-order request flow has been redesigned so a customer can understand the process before submitting.

## Flow
1. **Build your piece** in Create Your Own.
2. Click **Request made-to-order**.
3. **Review design** — form, material, finish, size, tone, engraving and estimated starting price are shown in one place.
4. **Your details** — name, email, phone, quantity, city, budget, needed-by date, purpose and delivery address.
5. Optional **reference image** filename capture and maker notes.
6. Customer confirms that final price/design/timeline will be reviewed before production.
7. A request ID is generated and the full brief is stored in localStorage for the current frontend-only demo.

The flow is intentionally frontend-only; no backend or payment service has been connected.
